# 可选图表支持

1. 询问用户是否需要 PrimeVue v4 Chart；不需要时不安装图表依赖或生成图表示例。
2. 如需要，查阅 [PrimeVue v4 Chart](https://v4.primevue.org/chart/) 及目标项目实际安装的 PrimeVue v4 版本，确认 Chart 组件及所需 Chart.js 等依赖的用法与兼容范围。若官方页面不可用，可检查对应版本的官方源码和包元数据，并如实报告不能验证的内容。
3. 检查拟安装的 Chart.js 和其他相关依赖的具体版本、直接及相关传递依赖的许可证、商业发行条件及保留声明要求。不得把 Chart.js 与任何商业图表产品混为同一个许可证，也不能根据旧版许可推断新版许可。
4. 把依赖、版本、许可结论和拟执行操作交给用户确认；明确获准后安装，并以最小示例验证。检查完成后清理临时示例或说明保留内容。

[Chart.js 官方仓库](https://github.com/chartjs/Chart.js) 可供核对来源；安装时仍应检查具体版本。
